Parallel Processing Architecture Clarification

  • Task-Parallel Processing (Active Pattern): Each GitHub Actions runner operates in its own isolated container environment, processing independent non-overlapping time slices (scene chunks). The chunks are concatenated with cross-fade continuity and audio synchronization.
  • RAM Isolation: Launching 4 workers provides 4 distinct 7GB virtual runners, NOT a single 28GB shared-memory machine. Large neural models must independently fit within runner memory.
  • Worker Failover: Unacknowledged task leases automatically expire after 300s and are reassigned to healthy runners.
